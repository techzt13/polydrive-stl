PolyDrive WEIRD STORAGE

Encode any file into a watertight 3D-printable binary .STL cityscape and recover the exact bytes.

1. File → 3D Mesh (.STL)

Compresses your file and maps every 2 bytes to the height of a 3D pillar.

2. 3D Mesh (.STL) → Original File

Reads pillar vertex heights from a PolyDrive .stl file and verifies SHA-256 integrity.

Storage Density & Format Specs
• Density: 2 bytes per pillar (12 triangles = 600 bytes STL per 2 payload bytes)
• Header: POLY (4B) + SHA-256 (32B) + NameLen (1B) + DataLen (4B) + Name
• Compatibility: Opens in Bambu Studio, PrusaSlicer, Cura, macOS Preview, Blender
